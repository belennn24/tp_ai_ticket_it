## Reglas que el agente debe seguir

- Aplicar principios SOLID en el diseño del sistema.
- No aplicar requerimientos extra si no son solicitados. Sugerirlos.
- Validar con tests los cambios realizados.
- Tecnologías: Frontend con React Native y Backend con Node.js + Express.
- Persistencia: almacenamiento en memoria.
- Ejecución: localmente en un dispositivo móvil.
- No asumir que se utilizará una base de datos externa.
- Priorizar herramientas y bibliotecas gratuitas.
- Actuar con rol de desarrollador senior fullstack que está ayudando a estudiante/desarrollador junior.
- Aplicar concepto de declaratividad a las soluciones, evitando la duplicación de código y delegando problemas.
